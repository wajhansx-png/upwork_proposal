- `src/lib/counter.ts` — WhatsApp counter add-on logic (planCounter: phone match, dedupe, first-contact count, replies; on an "old donors" task (`task.oldDonors`, set by words like "previous donors" or the switch on the manager screen → `/api/task-switch`, `setOldDonors`) any donor except "no" counts once per task via `task.countedDonors`, shared with her "Sent" tap); `extension-files.ts` the add-on source (read-only, never sends; treats chat opening/scroll/load as history, keeps unsent DMs in storage, retries on 5xx, honest badge); `zip.ts` zip writer. `src/app/api/counter/*` routes; CounterPanel in App.tsx.

- `src/lib/start-followup.ts` (`ensureFollowup`) keeps one live Vercel Workflow per running task (`workflows/follow-task.ts`, the one-minute clock). A run that finished, failed or no longer exists is replaced; called on every message and every `/api/agent/run`.
- `src/lib/ask.ts` + `askForUpdate` (agent.ts) + `/api/ask-update` — the manager's "Ask for update" button: one check-in message and loud push to her, worded differently every click (15 lines for DM tasks, 6 for others, real numbers only), 1-minute rest between clicks, ignores quiet hours, her silence still brings the usual pushes. Replies to her right after she reports a count or starts are kept short (`paceLine`: her ring already shows the count); direct questions still get the full status.

- `src/lib/saved.ts` + `/api/saved` + `src/app/Saved.tsx` — Saved messages (`db.saved`, newest first, max 50, optional heading, optional picture stored like proof screenshots via `saveImage`, served at /api/img/<id>): the manager writes, pastes the case post, or picks from 5 AI texts (`emotionalLines`, checked by `emotionalProblems`: no new claims/numbers/deadlines, no begging words; ready-made lines when the AI is off; the pay line is added) and saves; Areeba sees the same list at /areeba/messages (WhatsApp-like) in a grid of cards (2-line preview, "+ More" opens it) with Copy text, Copy image (PNG to clipboard), Save picture and Share (on phones: picture + text together via the share sheet; else wa.me text link); her taps show as "used by Areeba". - `src/lib/group-time.ts` — "⏰ Group Time" switch on the manager's Messages page (`/api/saved` action `groupTime`, `agent.groupTime`): while on, a push to Areeba every 20 min ("📢 Group Time — post this in all groups: …") naming the next saved message (never-used first, then used longest ago, never the same twice in a row), first one at once, none in quiet hours, none when nothing is saved. Tapping it opens /areeba/messages?m=<id> with that card highlighted (`sw.js` navigates an open tab to the exact link). Clock: `group-time-clock.ts` (`ensureGroupTimeClock`, workflow `workflows/follow-group-time.ts`) + `group-time-tick.ts`, also ticked by `/api/agent/run`.
- `src/lib/brain.ts` + `/api/brain` + `src/app/CaseBrain.tsx` (/manager/brain, "🧠 Case Brain" on the Messages page) — the manager's live-case rules as code: setup (name, age, boy/girl, total, facts one per line — only these are used), then LEFT n (first = UPDATE; down ≥2,000 since the last UPDATE, or ≥1,500 after 2 quiet hours = UPDATE; less = "Saved. Wait."; up = "Amount went up, please check."; 0 = DONE), 20 MIN (short message, next of 10 angles, all used before any repeats, round 2 uses other ready lines, never the same text twice), DRY (stronger main-group message + a freelancer-groups message with a hadith, plus DM/share reminder), DONE (his complete message). People maths (ceil left/2000, left/1000), the 3 exact hadiths and the pay ending are code. The AI (optional, "AI wording" switch) only writes 2 heart lines, dropped for banned words, medical words not in the facts, made-up numbers or the tired "fluid is…" opener. Each result: DO line, Copy, WhatsApp, Save to Messages.
- `src/app/api/*` — thin routes; logic lives in `src/lib`.
